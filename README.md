# Showrav Das — Personal Portfolio

Hugo portfolio based on Hugo Profile with a custom Publications section.

## Important
This package includes the complete Hugo Profile theme, `hugo.yaml`, a GitHub Pages workflow, and safe placeholder assets. Replace the placeholder profile/project images and `static/resume.pdf` with your real files if they are not already in your backup.

## GitHub Pages
The included workflow deploys the site through GitHub Pages Actions. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
